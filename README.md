# 🧠 Memory Card Game

An interactive memory card game built with React and Vite. Players flip cards to reveal hidden images and match pairs until all cards have been cleared from the board.

This project was created as part of my journey into React development, focusing on component-based architecture, state management, event handling, and dynamic user interfaces. Building this game helped me gain practical experience with React fundamentals while creating a fun and engaging user experience.

## 🕹️ How To Play

1. Click a card to reveal its hidden image.
2. Click a second card to attempt a match.
3. Matching cards remain face up.
4. Non-matching cards flip back over.
5. Continue until all pairs have been matched.
6. Match every pair to win the game.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Romie321/memory-card-game.git
```

Navigate to the project folder:

```bash
cd memory-card-game
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL provided by Vite in your browser.
