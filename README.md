# 📘 Memory Card Game
A React-based memory matching game built with Vite. This project is at its initial setup stage, using a minimal React + Vite configuration with hot module replacement and basic ESLint rules. Game logic, components, and UI will be added as development progresses.

## 🚀 Tech Stack
- React (functional components, hooks)

- Vite (fast dev server + build tooling)

- JavaScript

- HTML

## 🛠️ Getting Started
Install dependencies
bash
npm install
Run the development server
bash
npm run dev
Build for production
bash
npm run build
